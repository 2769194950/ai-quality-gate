# Changelog

## 1.0.0 - 2026-09-20

Initial public release candidate.

- Five-stage deterministic qgate workflow: requirements, design, build, review, verify.
- OpenCodeReview adapter with offline selection, grouping, rule handling, and live CLI boundary.
- Fail-closed stage evidence normalization for invalid or skipped OCR results.
- GitHub Actions workflow and reusable CI template.
- Public capability-boundary and supplementary test ledger.
